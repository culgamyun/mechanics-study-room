초안 · 학습 계획만 제공 본문과 문제를 작성·검토하기 전까지 학습 완료 처리와 퀴즈 응시는 제공하지 않습니다.

1. 오늘의 학습목표

  • 힘과 압력을 단위로 구별한다.
  • 같은 힘이 다른 면적에 작용하는 상황을 비교한다.

2. 선수지식

Day 17의 학습 흐름을 먼저 살펴봅니다. 이는 현재 교육 순서이며 세부 선수개념은 본문 작성 시 재검토합니다.

3. 30초 요약

학습 계획: 힘 · 압력 · 면적를 다룹니다. 본문·예제·도해·문제는 아직 작성 중이며, 이 페이지는 완성 강의가 아닙니다.

4. 가장 쉬운 설명

초안 · 설명 작성 예정. 힘을 일상 비유에서 시작해 설명할 예정입니다. 아직 검증된 본문이 없으므로 이 계획만으로 개념을 이해했다고 표시하지 마세요.

5. 생활 속 예시

예시 작성 예정. 힘과 연결되는 생활 장면을 선정하고 비유가 성립하지 않는 부분도 함께 작성합니다.

6. 리슨트와 정밀가공 현장 연결 예시

확인 필요. 리슨트의 실제 공정·장비·품번·조건을 확인하지 않았습니다. 공개 가능한 가상 사례를 작성하고 현장 적용 조건을 담당자에게 확인해야 합니다.

7. 정확한 정의

정의와 적용 조건 검토 예정. 힘, 압력, 면적의 정의를 공인 자료와 대조한 뒤 작성합니다.

8. 핵심 용어

  • 힘: 한국어·영어 표기, 쉬운 정의, 정확한 정의를 출처와 대조하여 보강할 예정.
  • 압력: 한국어·영어 표기, 쉬운 정의, 정확한 정의를 출처와 대조하여 보강할 예정.
  • 면적: 한국어·영어 표기, 쉬운 정의, 정확한 정의를 출처와 대조하여 보강할 예정.

9. 공식과 단위

공식·단위 작성 예정. 계산이 필요한 개념은 모든 기호, SI 단위, 적용 가정을 기록합니다. 수식이 불필요한 설계 주제는 정량 비교 기준과 그 이유를 명시합니다.

10. 단계별 계산 예제

계산 예제 미작성. 문제 조건 → 단위 변환 → 대입 → 검산 → 결과의 의미 순서로 작성할 예정입니다. 실장비 설정값은 예제로 추정하지 않습니다.

11. 정밀한 SVG 기술 도해

도해 미제작. 개념의 기준점·방향·관계를 직접 그린 SVG로 제공할 예정입니다. 초안에 정확한 도해가 존재하는 것으로 표시하지 않습니다.

12. 직관적인 이미지와 생성 프롬프트

이미지 프롬프트 작성 예정. 글자·수식·치수·회사 로고 없이 동일한 교육 일러스트 스타일을 사용합니다. 정확한 기술 관계는 SVG에서만 설명합니다.

13. 인터랙티브 시뮬레이션

적용성 검토 예정. 조작할 변수와 가정을 선정한 뒤 구현합니다. 아직 실행 가능한 시뮬레이션이 없습니다.

14. 흔한 오해

오해 목록 검토 예정. 힘의 정의와 비유를 혼동하는 경우, 이상적 모델을 실제 장비에 그대로 적용하는 경우를 검토합니다.

15. 안전 및 현장 확인사항

개념 학습: 이 초안은 학습 범위 안내입니다. 현장 담당자 확인 필요: 장비 모델·규격·허용조건·교육 절차. 감독 없이 실장비에서 수행 금지: 조작·배선·설정·가공·알람 해제·보호장치 변경. 제조사 매뉴얼과 현장 교육을 대체하지 않습니다.

16. 핵심 내용 5줄 요약

  1. 이 페이지는 완성 강의가 아닌 초안입니다.

  2. 예정 주제는 힘, 압력, 면적입니다.

  3. 정의·계산·도해는 작성 및 검토가 필요합니다.

  4. 책의 실제 장·절·페이지는 확인 필요입니다.

  5. 실장비 적용과 작업 승인을 제공하지 않습니다.

17. 확인문제 5개

출제 계획 · 응시 불가. 아래는 아직 정답이 없는 문항 설계 목록입니다.

  1. 개념 구별: 힘와 압력의 의미를 구별하는 문제 작성 예정.
  2. 간단한 계산: 힘 관련 기호·단위·가정을 명시한 수치 문제 작성 예정.
  3. 그림 해석: 힘 도해에서 입력·출력 또는 기준점을 읽는 문제 작성 예정.
  4. 현장 상황 판단: 실제 장비 적용 전에 확인할 정보와 승인 경계를 고르는 문제 작성 예정.
  5. 잘못된 설명 찾기: 힘의 흔한 오해를 판별하는 문제 작성 예정.

18. 각 문제의 해설

해설 미작성. 문제와 정답 검토가 완료된 후, 제출했을 때만 해설을 표시합니다. 지금은 점수를 매기거나 오답 복습을 생성하지 않습니다.

  • 힘: 쉬운 정의와 정확한 정의 카드 작성 예정
