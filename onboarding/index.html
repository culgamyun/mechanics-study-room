회사 교육을 받기 위한 5단계 길잡이

기존 품번의 도면을 읽고 생산·검사·포장·인계 흐름을 배우는 순서를 정리했습니다. 각 단계에서 사이트로 미리 익힐 일반 학습 내용과 회사가 제공해야 하는 현장 자료를 나누어 적었습니다.

가상 작업지시서 4종 · 가공부터 포장까지 실습

가상 핀으로 가공 품질 변수 익히기 D2를 처음 볼 때 · D2 학습 가이드 D5의 터릿과 드릴 · D5 학습 가이드 토르노스 등 스위스형 CNC 기초
이 페이지는 회사의 작업 절차가 아닙니다. 실제 작업 순서·설정값·알람 해제·공구 교환·보정·승인 기준은 아직 받은 자료가 없어 적지 않았습니다. 모든 ‘현장 자료’는 담당자에게서 받아 확인해야 합니다. 아래 체크는 개인 기록이며 작업 승인이 아닙니다.

1제품과 공정 이해

목적 · 담당할 기존 품번이 어떤 소재에서 어떤 공정을 거쳐 제품이 되는지 큰 흐름을 그린다.

배울 내용 · 일반 학습

  • 소재·공구·제품, 회전·이송 구분(Step 0 1단원)
  • 일반 선반과 에스코매틱 방식의 차이(1·8단원)
  • 회사 카탈로그의 공정 소개: 코일 소재, 바렐연마, 도금·후처리, 검사 장비(카탈로그 PDF 14~19)
Step 0 1단원Step 0 8단원

확인 기준

  • 한 품번의 공정 순서를 소재부터 포장까지 말할 수 있다(자기 점검)
  • 그린 공정도를 담당자가 확인해 주었다(담당자 확인)

필요한 현장 자료 현장 자료 확인 필요

  • 담당 품번 목록과 공정 순서(공정도)
  • 사용 호기(D2·D5 등)와 각 호기의 개조 이력 요약
  • 소재 사양(재질·선경)

담당자에게 물어볼 질문

  • 제가 처음 맡을 품번은 무엇이고, 어떤 공정을 거치나요?
  • 그 품번은 어느 호기에서 만들고, 그 호기는 어떻게 개조되었나요?

2도면과 검사 이해

목적 · 도면의 치수·공차를 읽고, 무엇을 어떤 측정기로 어떤 기준에 따라 검사하는지 이해한다.

배울 내용 · 일반 학습

  • mm와 µm, 분해능·정확도·공차의 구별(8단원)
  • 마이크로미터의 나사 원리(3단원)
  • 도면·측정의 일반 개념은 상세 Day 41~42(현재 초안)와 회사 교육으로 보완
Step 0 3단원(마이크로미터)Step 0 8단원(분해능·공차)

확인 기준

  • 도면에서 외경·길이·단차·공차를 찾아 말할 수 있다(자기 점검)
  • 측정기 사용법과 판정 기준을 담당자 시범 후 확인받았다(담당자 확인)

필요한 현장 자료 현장 자료 확인 필요

  • 담당 품번 도면(사내 열람 범위)
  • 검사기준서·측정 항목과 빈도
  • 사용 측정기 목록과 교정 상태
  • 비전검사 장비 운용 기준

담당자에게 물어볼 질문

  • 이 품번에서 가장 중요한 검사 항목과 허용 범위는 무엇인가요?
  • 측정값을 어디에 어떻게 기록하나요? 판정이 애매하면 누구에게 보고하나요?

3작업 준비와 생산

목적 · 작업 전 준비(소재·공구·장비 상태 확인)와 생산 중 관찰 포인트를 배운다. 조작은 담당자 지도 아래에서만 한다.

배울 내용 · 일반 학습

  • 회전부·지지부·돌출의 의미(4·5단원)
  • 캠·CNC의 동작 순서와 주기(6단원)
  • 모터·감속·이송의 흐름(7단원)
  • 절삭 용어는 Metal Cutting 2~3장
Step 0 4단원Step 0 6단원Step 0 7단원

확인 기준

  • 작업 전 확인 항목을 순서대로 말할 수 있다(자기 점검)
  • 담당자 감독 아래 준비 과정을 함께 수행했다(담당자 확인)

필요한 현장 자료 현장 자료 확인 필요

  • 호기별 작업표준서·작업 전 점검표
  • 공구 교환·보정 절차(승인 범위 포함)
  • 안전 규칙: 보호구, 덮개, 비상정지, 출입 제한
  • 알람 발생 시 보고 체계

담당자에게 물어볼 질문

  • 작업 전에 제가 반드시 확인해야 하는 항목은 무엇인가요?
  • 알람이나 이상음이 나면 저는 어디까지 하고 누구를 불러야 하나요?
  • 공구 교환·보정은 언제부터, 누구의 승인으로 할 수 있나요?

4검수와 포장·라벨·품번·수량·로트 확인 및 인계

목적 · 완성품을 검수하고, 포장·라벨에서 품번·수량·로트를 확인해 다음 공정이나 출하로 정확히 넘기는 방법을 배운다.

배울 내용 · 일반 학습

  • 측정값과 허용 범위 비교의 기본(8단원)
  • 기록을 정확히 남기는 습관(일일 기록 템플릿)
Step 0 8단원

확인 기준

  • 라벨에서 품번·수량·로트를 읽고 실물과 대조하는 순서를 말할 수 있다(자기 점검)
  • 포장·인계 절차를 담당자와 함께 수행했다(담당자 확인)

필요한 현장 자료 현장 자료 확인 필요

  • 포장 사양(용기·수량 단위)
  • 라벨 양식과 로트 번호 규칙
  • 인계 기록 양식과 인계 대상
  • 부적합품 격리·보고 절차

담당자에게 물어볼 질문

  • 로트 번호는 어떤 규칙으로 정해지고 어디에 기록되나요?
  • 수량이 맞지 않거나 라벨이 다르면 어떻게 처리하나요?

5담당자 확인 아래 전체 흐름 수행

목적 · 1~4단계를 이어서, 담당자가 지켜보는 가운데 한 품번의 준비 → 생산 → 검사 → 포장·인계를 처음부터 끝까지 수행한다.

배울 내용 · 일반 학습

  • Step 0 8단원 종합과 각 단계의 질문 목록 복습
  • 본인이 이해한 흐름을 공정도로 다시 그리기
Step 0 전체

확인 기준

  • 전체 흐름을 순서대로 설명할 수 있다(자기 점검)
  • 담당자가 수행을 지켜보고 다음 단계 허용 여부를 판단했다(담당자 판단 — 사이트 기록과 무관)

필요한 현장 자료 현장 자료 확인 필요

  • 회사의 교육 기록·작업 허가 절차
  • 단독 작업 전 필요한 승인 항목

담당자에게 물어볼 질문

  • 제가 혼자 해도 되는 범위와 반드시 확인받아야 하는 범위는 어디까지인가요?
  • 다음 품번이나 다른 호기로 넘어가는 기준은 무엇인가요?

담당자에게 들은 답, 받은 자료 이름, 날짜는 옵시디언 일일 기록의 ‘담당자에게 물을 질문’ 칸에 남기세요. 회사 내부 자료의 원문·도면·고객 정보는 이 사이트나 개인 클라우드에 올리지 않습니다.
